# airalarm-forecast-web

Статична сторінка: поточний стан повітряної тривоги у Вінницькому районі та груба оцінка,
чи почнеться тривога в найближчі 30 хв – 3 год (або чи триватиме, якщо вже діє).

**Це допоміжна оцінка, а не офіційне оповіщення.** Балістичні удари не прогнозуються.
Завжди орієнтуйтесь на офіційні сигнали та застосунок «Повітряна тривога».

## Як працює

- Сервера немає. Сторінка раз на 45 с бере офіційні тривоги з відкритого API
  [NEPTUN](https://neptun.in.ua) (`/api/v1/alerts`) і рахує все в браузері.
- `docs/forecast.js` — розрахунок (перенесений з Python-коду основного проєкту).
- `docs/targets.js` і `docs/models/targets_B.json` — **експериментальна** оцінка за цілями в повітрі
  (`/api/v1/threats`, через 6 с після запиту тривог): для кожної цілі моделюються можливі траєкторії.
  Параметри задано з міркувань здорового глузду, точність не перевірена. Тому ця частина лише
  піднімає текстовий рівень картки й показує список цілей, а відсотків не дає.
- `docs/models/alerts_A.json` — модель «за картою тривог»; `docs/models/duration.json` — тривалості минулих тривог.
- `docs/app.js` — завантаження даних і відображення.
- NEPTUN віддає тривоги двох рівнів, `red` і `yellow`. Обидва — справжні повітряні тривоги
  (жовтий — загроза БпЛА, червоний — ракетна небезпека), тож сторінка й модель вважають тривогою
  будь-який рівень, а сам рівень лише показують.

**Модель і тривалості пораховано на місяці даних за нинішніх правил тривог** (два рівні, з осені 2026 року).
Цього замало для повноцінної перевірки, тому:

- рівень на картках «Чи почнеться тривога» — експериментальна оцінка без відсотків
  (`"validated": false` у `alerts_A.json`). Рівень порівнює шанси з звичайними для цього горизонту:
  тривоги зараз часті, тож «Не вище звичайного» не означає «малоймовірно»;
- оцінка «Чи триватиме тривога» показується як попередня (`"preliminary": true` у `duration.json`),
  окремо для жовтого й червоного рівня; краї шкали — лише «менше 10 %» і «понад 90 %».

Повноцінні відсотки з'являться, коли перевірку вдасться повторити на достатній кількості тижнів.

## Хостинг

GitHub Pages з папки `docs/` гілки `main`. Після зміни `app.js`, `forecast.js` або `targets.js` оновіть `?v=`
в `docs/index.html` і в імпортах у `docs/app.js` (Pages кешує файли на 10 хв).

## Тести

```
node --test
```

`tests/vectors.json` і `tests/vectors_targets.json` містять приклади з відповідями Python-коду;
тести перевіряють, що JavaScript дає ті самі відповіді. Моделі й приклади оновлюються з основного проєкту:

```
.venv\Scripts\python research\export_web.py <шлях до цього репозиторію>
```

## Дані й подяки

- Тривоги: Карта повітряних тривог — NEPTUN, https://neptun.in.ua
- Історія тривог за останній місяць (навчання моделі й оцінка тривалості тривоги): alerts.in.ua, https://alerts.in.ua
